# Android UI Testing: Navigation Drawer

## Описание проекта

Проект по автоматизации тестирования пользовательского интерфейса Android-приложения с использованием Espresso.

Цель проекта: проверка корректности отображения главного экрана приложения и работы элементов интерфейса приложения с боковой навигацией (Navigation Drawer).

## Используемые технологии

- Java — язык программирования.
- Android Studio — среда разработки.
- Android SDK — инструменты разработки Android-приложений.
- Espresso 3.4.0 — автоматизация UI-тестирования.
- JUnit 4 — организация и выполнение тестов.
- AndroidX Test — инструменты инструментального тестирования.
- Hamcrest — проверка условий и элементов интерфейса.
- AndroidX Navigation — организация навигации между разделами приложения.
- Gradle — управление сборкой и зависимостями проекта.

## Объект тестирования

Android-приложение с боковым меню навигации (Navigation Drawer).

В приложении предусмотрены следующие разделы:

- Home — главный экран.
- Gallery — галерея.
- Slideshow — слайд-шоу.

## Реализованные проверки

**1. Проверка главного экрана (Home)**

- Запуск MainActivity.
- Проверка отображения главного экрана.
- Поиск текстового элемента по идентификатору `text_home`.
- Проверка наличия текста `This is home fragment`.

**2. Проверка контекста приложения**

- Получение контекста приложения через InstrumentationRegistry.
- Проверка соответствия имени пакета `ru.kkuzmichev.simpleappforespresso`.

## Запуск тестов

1. Открыть проект в Android Studio.
2. Дождаться завершения синхронизации Gradle.
3. Запустить Android Emulator или подключить Android-устройство с включённой отладкой по USB.
4. Выполнить запуск инструментальных тестов.

Запуск всех инструментальных тестов через терминал:

**Windows:**

```powershell
.\gradlew.bat connectedAndroidTest
```

**Linux / macOS:**

```bash
./gradlew connectedAndroidTest
```
